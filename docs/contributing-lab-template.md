# Lab page template

Every hands-on page uses these six sections, in this order.

```markdown
# Lab NN: Title

**Time:** NN minutes

## 1. Goal
One or two sentences.

## 2. Why it matters
Why would you do this in real life?

## 3. Steps
1. Numbered steps.
2. Copy-paste commands.

## 4. Expected result
What you should see.

![Screenshot placeholder](../assets/NN-result.png)

## 5. Stuck?
Common problems and fixes.

## 6. Going further
Optional extras. Cut this first if time is short.
```

## Writing rules

- Short sentences. Simple words. No idioms.
- Explain a new term the first time you use it.
- Every command must work from a clean clone.
- Run every lab before you publish it.
